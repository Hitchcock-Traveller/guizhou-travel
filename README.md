# 贵州避暑自驾之旅

**6天5夜 · 4大2小 · 黔西大环线**

一个纯前端旅行攻略网站，零框架、零依赖，单 HTML 文件即可运行。

🔗 **在线访问：** <https://hitchcock-traveller.github.io/guizhou-travel/>

---

## 行程概览

| 天数 | 路线 | 车程 | 核心体验 | 住宿 |
|------|------|------|----------|------|
| D1（8/8） | 洞口 → 清镇 | 6h / 370km | 羊皮洞瀑布 | 乡愁贵州·澜山酒店 |
| D2（8/9） | 清镇 → 纳雍 | 2.5h / 180km | 吊水岩瀑布（途经织金洞） | 总溪河陶源林宿 |
| D3（8/10） | 纳雍 → 六盘水 | 3.5h / 200km | 牂牁江·龙脊山 | 夜郎福地酒店 |
| D4（8/11） | 六盘水 → 关岭 | 2.5h / 160km | 冰臼群 + 滴水潭瀑布 | 渊府·霞渡精品民宿 |
| D5（8/12） | 关岭 → 安顺 | 1h / 80km | 铜鼓荡 + 大圣之眼 + 牛倒岩 | 安顺城市印象酒店 |
| D6（8/13） | 安顺 → 洞口 | 8h / 550km | 返程 | — |

## 网站特性

- **26 个内容板块**：从行程总览、每日地图、酒店选择到钓鱼专题、惊险户外，覆盖旅行全流程
- **7 天 SVG 手绘地图**：每日路线 + 停靠点 + 实时动画轨迹
- **11 个 B 站嵌入式视频**：航拍、探洞、漂流、瀑布实景，直接站内播放
- **44 张高清图片**：景点实拍、酒店环境、备选方案
- **折叠式交互设计**：手机端三层递进导航，桌面端全量滚动浏览
- **预算透明**：全程 ~¥8,200（住宿 ¥5,100 + 其他 ¥3,100），额外自费项目独立展示

## 技术架构

```
单文件架构，打开即用：
├── index.html          # 全部代码（HTML + CSS + JS）
├── README.md           # 本文件
└── .github/            # GitHub Pages 自动部署
```

### 技术约束

- **零依赖**：无框架、无 CDN、无 npm，纯原生 HTML/CSS/JS
- **ES5 语法**：`var` / `function`，兼容所有浏览器
- **CSS 动画**：仅使用 `transform` 和 `opacity`，保证 60fps
- **单文件部署**：397KB 一个文件搞定，GitHub Pages 直出

### 响应式适配

- **桌面端**：全量内容滚动浏览，双列卡片布局
- **手机端**：三层折叠导航（首页 → 分类 → 详情），触控友好

## 本地运行

无需任何构建工具，直接在浏览器打开即可：

```bash
# 方式一：直接双击 index.html
# 方式二：本地起个服务
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署到 GitHub Pages

```bash
git clone https://github.com/Hitchcock-Traveller/guizhou-travel.git
cd guizhou-travel
# 文件已自动部署到 gh-pages 分支，访问 https://<username>.github.io/guizhou-travel/
```
